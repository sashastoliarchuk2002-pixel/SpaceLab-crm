# Space Lab — CRM (окремий застосунок)

Це той самий CRM, що працював як артефакт у Claude — тільки тепер на власній базі даних
(Supabase) і на власному постійному посиланні (Vercel), яке можна встановити як застосунок
на телефон.

Нічого в логіці CRM не змінилось — всі функції ті самі (ліди, таймери по етапах, фото,
специфікація, реклама, контент, клієнтський трекер). Змінилось тільки **де зберігаються дані**.

---

## Що знадобиться (все безкоштовно на старт)

1. Акаунт на **github.com** (де лежатиме код)
2. Акаунт на **supabase.com** (база даних)
3. Акаунт на **vercel.com** (хостинг, постійне посилання)
4. Ключ API з **console.anthropic.com** (тільки якщо хочете, щоб працювала генерація
   контенту та аналіз голосового опитування — це єдина платна складова, оплата йде
   окремо від підписки на claude.ai, за фактичне використання, зазвичай копійки)

---

## Крок 1. Supabase (база даних)

1. Зареєструйтесь на supabase.com → **New project**
2. Дайте проєкту назву (напр. `spacelab-crm`), задайте пароль бази (збережіть його) → **Create**
3. Зачекайте ~2 хвилини, поки проєкт створюється
4. Зліва: **SQL Editor** → **New query** → відкрийте файл `supabase.sql` з цього проєкту,
   скопіюйте весь вміст, вставте і натисніть **Run**
5. Зліва: **Settings** → **API** — тут два значення, які знадобляться на кроці 4:
   - **Project URL**
   - **anon public** ключ

---

## Крок 2. Anthropic API ключ (необов'язково, тільки для ШІ-функцій)

1. Зареєструйтесь на console.anthropic.com
2. **Settings → API Keys → Create Key**
3. Скопіюйте ключ (він показується лише один раз)

Якщо пропустите цей крок — весь CRM працюватиме нормально, крім кнопок
"Проаналізувати відповіді" (голосове опитування) і "Згенерувати" (контент).

---

## Крок 3. Викласти код на GitHub

1. Зареєструйтесь на github.com, якщо ще немає акаунту
2. **New repository** → назва `spacelab-crm` → **Create repository**
3. Завантажте вміст цього проєкту (розпакований) у репозиторій — найпростіше через
   кнопку **"uploading an existing file"** на сторінці репозиторію, перетягнути всі файли
   і натиснути **Commit changes**

---

## Крок 4. Розгорнути на Vercel

1. Зареєструйтесь на vercel.com **через свій GitHub-акаунт** (це спростить наступний крок)
2. **Add New → Project** → оберіть репозиторій `spacelab-crm` → **Import**
3. Перед тим, як тиснути Deploy, розгорніть **Environment Variables** і додайте три змінні:

   | Name | Value |
   |---|---|
   | `VITE_SUPABASE_URL` | Project URL з кроку 1 |
   | `VITE_SUPABASE_ANON_KEY` | anon public ключ з кроку 1 |
   | `ANTHROPIC_API_KEY` | ключ з кроку 2 (можна пропустити) |

4. Натисніть **Deploy**, зачекайте ~1-2 хвилини
5. Готово — Vercel видасть постійне посилання типу `spacelab-crm.vercel.app`

---

## Крок 5. Встановити як застосунок на телефон

**Android (Chrome):** відкрийте посилання → три крапки → **"Встановити застосунок"**

**iPhone (Safari):** відкрийте посилання → кнопка "Поділитись" → **"На екран Домівки"**

Іконка з'явиться на головному екрані й відкриватиметься на весь екран, як звичайна програма.
Дайте те саме посилання дівчині — на її телефоні зробіть те саме, і дані будуть
синхронізовані між вами в реальному часі через Supabase.

---

## Як далі вносити зміни в код

Якщо захочете щось доробити — просто попросіть Claude внести зміни у файл `src/App.jsx`
(як і раніше), а потім:
1. Завантажте оновлений файл на GitHub (той самий репозиторій, замінити файл)
2. Vercel сам перезбере й оновить сайт за ~1 хвилину — нічого додатково натискати не треба

---

## Чесно про обмеження

- **Клієнтський трекер** (`?order=КОД`) працює так само, як і раніше — просто тепер це
  реальне окреме посилання, а не залежить від публікації артефакту в Claude
- **Видалення адмін-захисту:** зараз, як і в останній версії в Claude, внутрішня CRM
  відкривається на базовому посиланні без пароля. Якщо захочете додати захист входу —
  скажіть, це можна зробити окремим кроком (простий пароль або справжній логін через Supabase Auth)
- Supabase безкоштовний план має ліміти (500MB бази, призупиняється після тижня
  неактивності — просто відкриється трохи повільніше при першому заході після паузи)
